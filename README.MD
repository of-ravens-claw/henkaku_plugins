# henkaku_plugins
Fork of the HENkaku plugins, with support for more firmware versions.

The base of this fork is TheFlow's h-encore, available here: https://github.com/theofficialflow/h-encore

## Additions:
* Support for 3.30 - 3.57, 3.61 - 3.63, 3.69 - 3.74.
* Correctly replaces the version string on DEX/TOOL firmware. (Currently 3.65 only!)
